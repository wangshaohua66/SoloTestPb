# 系统设计文档 - 网页数据采集工具

## 1. 概述

本系统是一个功能完整的网页数据采集框架，采用模块化设计，支持多种网页结构的数据提取，具备高可靠性和可扩展性。

| 模块 | 类名 | 主要职责 |
|------|------|----------|
| 配置管理 | ScraperConfig, ConfigLoader | 配置定义、加载、解析 |

| 数据导出 | DataExporter | CSV/Excel/JSON格式导出 |
| 核心采集器 | WebScraper | 模块协调、流程控制、状态管理 |

## 3. 详细设计

### 3.1 配置管理模块

**类结构**：
```python
@dataclass
class ScraperConfig:
    name: str                          # 任务名称
    start_urls: List[str]              # 起始URL列表
    selectors: List[SelectorConfig]    # 选择器配置列表
    login: Optional[LoginConfig]       # 登录配置
    pagination: PaginationConfig       # 分页配置
    request: RequestConfig             # 请求配置
    rate_limit: RateLimitConfig        # 速率限制配置
    proxy: ProxyConfig                 # 代理配置
    export: ExportConfig               # 导出配置
    retry_times: int                   # 重试次数
    retry_delay: float                 # 重试间隔
```

**配置加载流程**：
1. 支持YAML和JSON两种格式
2. ConfigLoader.from_yaml() / from_json() 读取文件
3. 转换为dataclass对象
4. 提供默认值保证向后兼容

### 3.2 请求管理模块

**核心特性**：
- 基于requests.Session的持久连接
- 指数退避重试策略
- 默认浏览器User-Agent
- 支持代理和自定义Cookie

**重试逻辑**：
```
重试次数: 3次
重试间隔: 2s, 4s, 8s (指数增长 + 随机抖动)
重试条件: 网络错误、超时、5xx状态码
```

### 3.3 数据提取模块

**两种提取方式**：

1. **CSS选择器** (BeautifulSoup)
   - 语法简洁，易于编写
   - 适合常规页面结构
   - 示例：`div.product > h3.title`

2. **XPath** (lxml)
   - 功能强大，支持复杂逻辑
   - 适合嵌套结构和属性定位
   - 示例：`//div[@class='product']//h3/@title`

**提取方法**：
```python
extract_by_css()     # CSS选择器提取
extract_by_xpath()   # XPath提取
extract()            # 自动选择方法
extract_multiple()   # 批量提取
```

### 3.4 分页处理模块

**两种分页模式**：

1. **URL参数模式**
   - 适用于 `?page=1` 形式的分页
   - 自动生成所有分页URL
   - 示例：`start_page=1, max_pages=10` → 生成10个URL

2. **下一页链接模式**
   - 通过选择器定位"下一页"链接
   - 支持相对路径解析
   - 自动跟踪直到没有下一页

**URL解析**：
- 支持绝对路径、根路径、相对路径
- 自动处理 `../` 路径片段

### 3.5 认证管理模块

**两种认证方式**：

1. **表单登录** (Form Login)
   - 自动获取隐藏字段
   - 支持额外表单字段
   - 成功标志验证

2. **Token认证** (Token Login)
   - POST到认证API
   - 解析返回的JWT/Token
   - 自动添加Authorization头

**Cookie管理**：
```python
set_cookies()        # 设置Cookie
get_cookies()        # 获取Cookie
save_cookies()       # 保存到文件
load_cookies()       # 从文件加载
```

### 3.6 代理管理模块

**代理轮换策略**：

| 策略 | 说明 |
|------|------|
| round_robin | 轮询方式，依次使用每个代理 |
| random | 随机选择代理 |
| weighted | 按成功率加权选择 |

**健康检测**：
- 初始化时测试所有代理
- 支持动态添加/移除代理
- 自动标记失败/成功
- 失败超过阈值自动剔除

### 3.7 速率限制模块

**限制策略**：

1. **固定间隔**：min_delay = max_delay
2. **随机间隔**：min_delay ~ max_delay
3. **并发控制**：限制同时进行的请求数
4. **滑动窗口**：每分钟最大请求数

**实现机制**：
- 使用deque记录请求时间戳
- 线程锁保护共享状态
- 上下文管理器简化使用

### 3.8 数据导出模块

**支持格式**：

| 格式 | 依赖 | 说明 |
|------|------|------|
| JSON | 内置 | 保留完整结构，支持嵌套 |
| CSV | 内置 | 列表/字典序列化为字符串 |
| Excel | pandas+openpyxl | 支持多工作表 |

**导出方法**：
```python
export_to_json()     # 导出JSON
export_to_csv()      # 导出CSV
export_to_excel()    # 导出Excel
export()             # 多格式同时导出
export_multiple_sheets()  # Excel多工作表
```

## 4. 核心流程

### 4.1 采集主流程

```
开始
  │
  ▼
初始化模块
  │
  ▼
登录 (如需要)
  │
  ▼
收集所有URL ─────────┐
  │                   │
  ▼                   │
遍历每个URL           │
  │                   │
  ├── 速率限制等待 ◀───┘
  │
  ├── 获取代理
  │
  ├── 发送请求 (重试)
  │       │
  │       ├── 成功 → 标记代理成功
  │       │
  │       └── 失败 → 标记代理失败，重试
  │
  ├── 解析HTML
  │
  ├── 提取数据
  │
  └── 保存到结果集
  │
  ▼
导出数据
  │
  ▼
输出统计
  │
  ▼
结束
```

### 4.2 错误处理流程

```
请求失败
  │
  ├── 重试次数未用完?
  │       ├── 是 → 等待 (指数退避) → 重试
  │       │
  │       └── 否 → 记录失败
  │                 │
  │                 ├── 有代理? → 标记代理失败
  │                 │
  │                 └── 更新统计
  │
  ▼
继续下个URL
```

## 6. 性能与可靠性

### 6.1 性能优化

1. **连接复用**：使用Session保持TCP连接
2. **并发控制**：可配置并发数
3. **延迟随机化**：模拟真实访问模式
4. **代理池**：分散请求到多个IP

### 6.2 可靠性保障

| 保障措施 | 说明 | 效果 |
|----------|------|------|
| 指数退避重试 | 避免瞬时错误导致失败 | 减少偶发失败 |
| 代理健康检测 | 自动剔除失效代理 | 提高成功率 |
| 失败计数 | 超过阈值移除低质量代理 | 优化代理池 |
| 详细统计 | 便于定位问题 | 快速排查 |

### 6.3 数据完整率保障

为确保采集1000个页面时数据完整率不低于99%，系统具备：

1. **自动重试机制**
   - 网络错误自动重试3次
   - 重试间隔指数增长
   - 随机抖动避免拥塞

2. **错误容忍**
   - 单个页面失败不影响其他页面
   - 详细记录失败原因

3. **代理容错**
   - 失败代理自动轮换
   - 成功率低的代理被剔除

## 8. 安全考虑

### 8.1 数据安全

- 密码等敏感信息不在日志输出
- Cookie文件建议加密存储
- 采集数据注意隐私保护

### 8.2 请求安全

- 默认启用SSL证书验证
- 不自动信任自签名证书
- 可配置关闭（不推荐）

### 8.3 使用合规

- 建议遵守robots.txt
- 设置合理请求间隔
- 不用于恶意用途

## 10. 部署与运行

### 10.1 环境要求

- Python 3.8+ (推荐3.12)
- 网络连接
- 足够的磁盘空间存储导出数据

### 10.2 依赖安装

```bash
pip install -r requirements.txt
```

### 10.3 运行方式

1. **配置文件方式** (推荐)
   ```bash
   python main.py -c config.yaml
   ```

2. **命令行参数方式**
   ```bash
   python main.py -u https://example.com -s title|h1|css
   ```

3. **编程接口方式**
   ```python
   from auto_web_scraper import WebScraper
   scraper = WebScraper(config_file="config.yaml")
   data = scraper.scrape()
   ```
