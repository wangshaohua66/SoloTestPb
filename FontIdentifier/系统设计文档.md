# 书法字体识别器 - 系统设计文档

## 1. 项目概述

### 1.1 项目背景
面向书法研究者和爱好者，提供书法字体识别工具，帮助用户快速识别书法作品的字体类型，了解字体特征和历史背景。

### 1.2 项目目标
- 实现书法字体的智能识别
- 提供丰富的字体特征信息
- 支持识别结果的导出
- 记录识别历史便于查阅

## 3. 模块设计

### 3.1 后端模块

#### 3.1.1 字体库模块 (font_library.py)

**功能描述**：内置书法字体信息库

**核心数据结构**：
```python
FONT_LIBRARY = {
    "字体名称": {
        "id": "唯一标识",
        "name": "字体名称",
        "english_name": "英文名称",
        "description": "字体简介",
        "history": "历史沿革",
        "stroke_features": "笔画特征字典",
        "structure_features": "结构特征字典",
        "style_features": "风格特征列表",
        "representative_works": "代表作品列表",
        "key_characteristics": "关键识别特征列表"
    }
}
```

**支持的字体**：楷书、行书、草书、隶书、篆书

#### 3.1.2 特征提取模块 (feature_extractor.py)

**功能描述**：从用户输入文本中提取书法特征

**核心方法**：
- `extract_features(text)`: 从文本提取特征，返回特征分数
- `analyze_image_features()`: 图像特征分析（预留接口）

**特征分类**：
1. 笔画特征关键词
2. 结构特征关键词
3. 风格特征关键词

**算法逻辑**：
1. 遍历各字体的特征关键词
2. 统计文本中匹配的关键词数量
3. 计算各字体的特征匹配分数

#### 3.1.3 字体识别模块 (font_recognizer.py)

**功能描述**：根据提取的特征进行字体识别

**核心方法**：
- `recognize(features, input_text)`: 执行字体识别
- `_build_result()`: 构建识别结果
- `_generate_analysis()`: 生成分析说明
- `_find_similar_fonts()`: 查找相似字体

**识别流程**：
1. 获取各字体的特征分数
2. 计算置信度（分数占比）
3. 排序确定主要识别结果
4. 生成详细分析说明
5. 查找相似字体进行对比

#### 3.1.4 数据库模块 (database.py)

**功能描述**：SQLite数据库操作封装

**数据库表结构**：

**识别历史表 (recognition_history)**：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| input_text | TEXT | 用户输入描述 |
| recognized_font | TEXT | 识别出的字体 |
| confidence | REAL | 置信度 |
| result_json | TEXT | 完整结果JSON |
| created_at | TIMESTAMP | 创建时间 |

**字体信息表 (fonts)**：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| name | TEXT | 字体名称（唯一） |
| english_name | TEXT | 英文名称 |
| description | TEXT | 描述 |
| history | TEXT | 历史 |
| stroke_features | TEXT | 笔画特征JSON |
| structure_features | TEXT | 结构特征JSON |
| style_features | TEXT | 风格特征JSON |
| representative_works | TEXT | 代表作品JSON |
| key_characteristics | TEXT | 关键特征JSON |
| created_at | TIMESTAMP | 创建时间 |

**核心方法**：
- `add_recognition()`: 添加识别记录
- `get_recognition_history()`: 获取历史记录
- `get_recognition_by_id()`: 根据ID获取记录
- `get_recognition_count()`: 获取记录总数
- `get_font_recognition_stats()`: 获取字体统计

#### 3.1.5 图像处理模块 (image_processor.py)

**功能描述**：使用Pillow库处理上传的书法作品图片，提取图像特征

**依赖库**：
- Pillow：图像处理
- NumPy：数值计算（可选，用于提高精度）

**核心方法**：
- `validate_image(file_storage)`: 验证上传的图片（格式、大小）
- `process_image(file_storage)`: 处理图片并提取特征
- `_extract_color_features(img)`: 提取颜色特征
- `_extract_texture_features(img)`: 提取纹理特征
- `_extract_stroke_features(img)`: 提取笔画特征
- `_extract_structure_features(img)`: 提取结构特征
- `_predict_font(features)`: 基于图像特征预测字体
- `generate_description(features)`: 根据特征生成文字描述
- `image_to_base64(file_storage)`: 图片转Base64编码

**提取的图像特征**：

| 特征类别 | 具体特征 | 说明 |
|---------|---------|------|
| 图像信息 | 宽度、高度、格式、宽高比 | 基本图片信息 |
| 颜色特征 | RGB均值、标准差、灰度均值、亮度、对比度 | 颜色和光照分析 |
| 纹理特征 | 边缘强度、清晰度、边缘密度 | 笔触纹理分析 |
| 笔画特征 | 墨迹密度、笔画宽度、水平/垂直变化度 | 笔画形态分析 |
| 结构特征 | 结构类型、垂直/水平平衡度 | 整体结构分析 |

**字体预测算法**：
基于启发式规则的多特征融合：
1. 规整度：判断楷书/篆书 vs 行书/草书
2. 笔画粗细：判断隶书/篆书 vs 行书/草书
3. 边缘清晰度：判断楷书 vs 草书
4. 宽高比：判断篆书(纵向) vs 隶书(横向)
5. 平衡度：判断篆书(对称) vs 其他

**错误处理**：
- 依赖库未安装时给出友好提示
- 支持优雅降级，文字识别功能不受影响

#### 3.1.6 报告生成模块 (report_generator.py)

**功能描述**：生成识别结果报告

### 4.4 图像特征融合算法

图片识别采用多特征融合策略：
- **图像特征权重**：70%（基于图像分析的直接证据）
- **文本特征权重**：30%（基于图像描述的间接证据）

融合公式：
```
综合得分(字体) = 图像得分 * 0.7 + 文本得分 * 0.3
```

## 5. 算法设计

### 5.1 特征匹配算法

**算法思想**：基于关键词的特征权重匹配

**实现步骤**：
1. 建立各字体的特征关键词库（笔画、结构、风格三类）
2. 对用户输入文本进行分词匹配
3. 统计各字体的匹配关键词数量
4. 按类别计算综合得分
5. 归一化得到置信度

**置信度计算公式**：
```
置信度(字体A) = 字体A匹配分数 / 所有字体匹配分数之和
```

**相似度映射**：
- 楷书 ↔ 行书、隶书
- 行书 ↔ 楷书、草书
- 草书 ↔ 行书、楷书
- 隶书 ↔ 楷书、篆书
- 篆书 ↔ 隶书、楷书

### 5.2 相似字体判别

基于书法字体演化关系建立相似性映射：
```
篆书 → 隶书 → 楷书 → 行书 → 草书
```

相邻字体具有较高相似性，提供区别要点帮助用户判断。
