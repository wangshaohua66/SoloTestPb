# Excel数据合并工具 - 系统设计文档

## 1. 系统概述

### 1.1 项目背景
本工具是一个用于自动化合并多个Excel文件的Python应用，支持多种合并策略，帮助财务和数据分析人员快速整合数据。

### 1.2 功能目标
- 支持多个Excel文件按行合并（追加数据）
- 支持多个Excel文件按列合并（合并字段）
- 支持按指定键值进行关联合并（类似SQL JOIN）
- 支持处理不同格式的Excel文件（xlsx、xls、csv）
- 支持合并前数据清洗，包括去重、空值处理
- 生成合并报告，记录合并记录数和处理异常

## 2. 系统架构

### 2.1 整体架构

```
Excel数据合并工具
    ├── 命令行接口 (CLI)
    ├── 合并核心模块 (ExcelMerger)
    ├── 文件读取模块 (ExcelReader)
    ├── 数据清洗模块 (DataCleaner)
    └── 报告生成模块 (MergeReporter)
```

### 2.2 模块依赖关系

```
main.py (CLI)
    ↓
ExcelMerger (合并核心)
    ↙       ↓         ↘
ExcelReader  DataCleaner  MergeReporter
  (读文件)   (数据清洗)    (生成报告)
```

## 3. 详细模块设计

### 3.1 ExcelReader - 文件读取模块

#### 功能说明
负责读取各种格式的Excel文件和CSV文件，获取文件信息和工作表名称。

#### 类设计
```python
class ExcelReader:
    - SUPPORTED_EXTENSIONS: 支持的文件扩展名
    - last_file_info: 最后读取的文件信息
    
    + read_file(file_path, sheet_name=None, **kwargs): 读取单个文件
    + read_multiple_files(file_paths, sheet_name=None, **kwargs): 批量读取多个文件
    + get_files_from_directory(directory, extensions=None): 从目录获取支持的文件
    + get_file_info(file_path): 获取文件信息
    + get_sheet_names(file_path): 获取工作表名称列表
```

#### 关键实现要点
1. 使用pandas库读取文件
2. 对xlsx使用openpyxl引擎，对xls使用xlrd引擎
3. 使用with语句确保Excel文件句柄正确关闭
4. 记录每个文件的行数、列名等元数据

### 3.2 DataCleaner - 数据清洗模块

#### 功能说明
提供数据清洗功能，包括去重、空值处理、删除空行空列等。

#### 类设计
```python
class DataCleaner:
    - cleaning_stats: 清洗统计信息
    
    + remove_duplicates(df, subset=None, keep='first'): 去除重复行
    + handle_missing_values(df, strategy='drop', fill_value=None, columns=None): 处理缺失值
    + drop_empty_rows(df, threshold=0.0): 删除空行
    + drop_empty_columns(df, threshold=0.0): 删除空列
    + clean_data(df, **kwargs): 综合数据清洗入口
    + get_cleaning_stats(): 获取清洗统计
    + reset_stats(): 重置统计信息
```

#### 缺失值处理策略
1. **drop**: 删除包含缺失值的行
2. **drop_all**: 删除全部为缺失值的行
3. **fill**: 用指定值填充
4. **ffill**: 用前一个值填充（向前填充）
5. **bfill**: 用后一个值填充（向后填充）
6. **mean**: 用均值填充（仅数值列）
7. **median**: 用中位数填充（仅数值列）
8. **mode**: 用众数填充

#### 兼容性考虑
- pandas高版本中fillna()不再支持subset参数，通过列遍历实现
- 处理不同数据类型的缺失值填充策略

### 3.3 ExcelMerger - 合并核心模块

#### 功能说明
提供三种合并策略，是系统的核心业务逻辑模块。

#### 类设计
```python
class ExcelMerger:
    - reader: ExcelReader实例
    - cleaner: DataCleaner实例
    - merge_stats: 合并统计信息
    
    + merge_by_row(file_paths, **kwargs): 按行合并（追加数据）
    + merge_by_column(file_paths, **kwargs): 按列合并（合并字段）
    + merge_by_join(file_paths, join_key, how='inner', **kwargs): 关联合并
    + merge(file_paths, strategy='row', **kwargs): 统一合并入口
    + save_result(df, output_path, sheet_name='Sheet1', index=False, **kwargs): 保存结果
    + get_merge_stats(): 获取合并统计
```

#### 合并策略说明

##### 1. 按行合并 (Row Merge)
- **适用场景**: 多个文件结构相同，需要合并为一个大表
- **实现方式**: 使用pandas.concat沿axis=0方向合并
- **额外功能**: 自动去重、缺失值处理

##### 2. 按列合并 (Column Merge)
- **适用场景**: 多个文件包含同一实体的不同字段，需要横向合并
- **实现方式**: 使用pandas.concat沿axis=1方向合并
- **连接方式**: inner join / outer join

##### 3. 关联合并 (Join Merge)
- **适用场景**: 多个文件有共同的关联键，需要类似SQL的表连接
- **实现方式**: 使用pandas.merge多次连接
- **支持的连接类型**:
  - inner join: 内连接，只保留匹配的行
  - left join: 左连接，保留左表所有行
  - right join: 右连接，保留右表所有行
  - outer join: 外连接，保留所有行

### 3.4 MergeReporter - 报告生成模块

#### 功能说明
生成合并过程的详细报告，包括处理统计和异常信息。

#### 类设计
```python
class MergeReporter:
    - reports: 报告历史列表
    
    + generate_report(merge_stats, output_dir=None, format='txt'): 生成报告
    + print_summary(merge_stats): 打印合并摘要到控制台
    + get_all_reports(): 获取所有报告
    + clear_reports(): 清空报告列表
```

#### 报告格式
1. **文本格式 (txt)**: 人类可读的格式化报告
2. **JSON格式**: 机器可读的结构化报告

#### 报告内容
- 合并时间戳
- 合并策略类型
- 处理文件数、成功数、失败数
- 原始行数、合并后行数
- 去重数量、缺失值处理数量
- 关联合并的关联键和连接类型
- 每个文件的处理详情和错误信息
- 合并后的列名列表

### 3.5 命令行接口 (CLI)

#### 设计说明
使用Click库实现直观的命令行接口。

#### 命令结构
```bash
# 按行合并
python main.py merge-row --input-dir <dir> --output <file> [options]

# 按列合并
python main.py merge-col --input-dir <dir> --output <file> [options]

# 关联合并
python main.py merge-join --input-dir <dir> --output <file> --key <key> [options]

# 列出目录文件
python main.py list-files <directory>
```

#### 主要参数
- `--input-dir/-i`: 输入目录路径
- `--output/-o`: 输出文件路径
- `--sheet-name/-s`: 工作表名称
- `--key/-k`: 关联合并的关联键
- `--join-type`: 关联类型（inner/left/right/outer）
- `--remove-duplicates/--no-remove-duplicates`: 是否去重
- `--missing-strategy`: 缺失值处理策略
- `--report-dir`: 报告输出目录
- `--report-format`: 报告格式（txt/json）

## 4. 数据流程设计

### 4.1 按行合并数据流程

```
输入目录
    ↓
获取所有Excel/CSV文件列表
    ↓
[循环处理每个文件]
    读取文件为DataFrame
    记录文件元信息
    ↓
[合并所有DataFrame]
    ↓
数据清洗（去重、缺失值处理）
    ↓
保存结果到输出文件
    ↓
生成合并报告
```

### 4.2 关联合并数据流程

```
输入目录
    ↓
获取所有Excel/CSV文件列表
    ↓
[循环处理每个文件]
    读取文件为DataFrame
    检查是否包含关联键列
    记录文件元信息
    ↓
[逐步连接所有DataFrame]
    第一个文件作为左表
    后续文件依次右连接
    ↓
保存结果到输出文件
    ↓
生成合并报告
```

## 6. 性能设计

### 6.1 性能目标
- 合并10个10000行的Excel文件完成时间不超过30秒

### 6.2 优化策略

1. **内存优化**
   - 使用pandas高效的数据结构
   - 避免不必要的数据复制

2. **IO优化**
   - 使用pandas内置的高效文件读写引擎
   - 批量处理文件，减少IO次数

3. **算法优化**
   - 去重操作使用pandas内置的高效算法
   - 关联合并使用索引优化

## 8. 异常处理设计

### 8.1 主要异常类型
1. **文件不存在**: FileNotFoundError
2. **不支持的文件格式**: ValueError
3. **读取失败**: Exception（包含具体错误信息）
4. **缺少关联键列**: ValueError
5. **不支持的合并策略**: ValueError

### 8.2 异常处理策略
1. 单文件处理失败不中断整个合并流程
2. 记录每个文件的错误信息到报告
3. 控制台输出友好的错误提示
4. 统计成功和失败的文件数量

## 10. 部署与使用

### 10.1 环境要求
- Python 3.8+
- 支持Windows、Linux、macOS

### 10.2 安装步骤
```bash
# 克隆项目
git clone <repository-url>
cd ExcelMerger

# 安装依赖
pip install -r requirements.txt

# 运行测试
pytest

# 查看帮助
python main.py --help
```

### 10.3 使用示例

#### 示例1：按行合并销售数据
```bash
# 多个月份的销售数据合并为年度数据
python main.py merge-row --input-dir ./sales/2024 --output ./merged/2024_sales.xlsx --remove-duplicates --missing-strategy fill
```

#### 示例2：关联合并客户信息
```bash
# 关联客户基本信息、订单、支付记录
python main.py merge-join --input-dir ./customer --key customer_id --join-type left --output ./customer_merged.xlsx
```

#### 示例3：编程接口使用
```python
from excel_merger import ExcelMerger, MergeReporter

merger = ExcelMerger()
reporter = MergeReporter()

file_paths = ['file1.xlsx', 'file2.xlsx', 'file3.xlsx']

# 按行合并
result, stats = merger.merge_by_row(file_paths, remove_duplicates=True)

# 保存结果
merger.save_result(result, 'output.xlsx')

# 生成报告
report = reporter.generate_report(stats, output_dir='./reports')
```
