# PDF文档处理工具 - 系统设计文档

## 1. 项目概述

### 1.1 项目背景
本项目是一个用于自动化处理PDF文档的工具，支持合并、拆分、提取文本和图片等操作，帮助办公人员提高文档处理效率。

### 1.2 功能清单
- 多个PDF文件合并为一个文件
- PDF文件按页码范围拆分
- 从PDF中提取文本内容，保存为TXT文件
- 从PDF中提取图片，保存为原始格式
- 添加页码、页眉页脚
- PDF加密和解密，可设置密码和权限

### 1.3 技术栈
- 编程语言：Python 3
- PDF处理：PyPDF2、pdfplumber
- 图像提取：pdf2image
- 测试框架：pytest + Allure
- 代码规范：PEP8

## 2. 系统架构

### 2.1 架构设计
采用模块化设计，每个功能独立为一个模块，通过CLI接口对外提供服务。

```
PdfTool/
├── src/
│   ├── pdf_merger.py        # PDF合并模块
│   ├── pdf_splitter.py       # PDF拆分模块
│   ├── pdf_text_extractor.py # 文本提取模块
│   ├── pdf_image_extractor.py # 图片提取模块
│   ├── pdf_header_footer.py  # 页眉页脚模块
│   ├── pdf_security.py       # 加密解密模块
│   └── cli.py               # 命令行接口
├── tests/                    # 单元测试
├── docs/                     # 文档
└── main.py                  # 程序入口
```

## 3. 模块详细设计

### 3.1 PDF合并模块 (pdf_merger.py)

#### 类定义
```python
class PDFMerger:
    """PDF合并器，用于将多个PDF文件合并为一个文件"""
    
    def merge_pdfs(self, input_paths: List[str], output_path: str) -> None:
        """合并多个PDF文件"""
```

#### 输入输出
- 输入：PDF文件路径列表
- 输出：合并后的PDF文件

#### 异常处理
- ValueError：输入文件列表为空
- FileNotFoundError：输入文件不存在

#### 类定义
```python
class PDFSplitter:
    """PDF拆分器，用于将PDF文件按页码范围拆分"""
    
    def split_by_range(self, input_path: str, output_path: str, 
                       start_page: int, end_page: int) -> None:
        """按页码范围拆分PDF"""
```

#### 输入输出
- 输入：PDF文件路径、页码范围

#### 异常处理

- ValueError：页码范围不合法

```python
class PDFSecurity:
```

#### 异常处理
- FileNotFoundError：输入文件不存在
- ValueError：密码为空或文件未加密

## 4. 接口设计

### 4.1 命令行接口 (CLI)

通过Click库提供以下命令：

```bash
# 合并PDF
python main.py merge --inputs file1.pdf file2.pdf --output merged.pdf

# 拆分PDF
python main.py split --input input.pdf --output output.pdf --start 1 --end 5

# 提取文本
python main.py extract-text --input input.pdf --output output.txt

# 提取图片
python main.py extract-images --input input.pdf --output-dir ./images

# 添加页码
python main.py add-page-numbers --input input.pdf --output output.pdf

# 添加页眉页脚
python main.py add-header-footer --input input.pdf --output output.pdf --header "页眉"

# 加密PDF
python main.py encrypt --input input.pdf --output output.pdf --password "123456"

# 解密PDF
python main.py decrypt --input input.pdf --output output.pdf --password "123456"
```

### 7.2 外部依赖说明（Poppler）

**Poppler工具（PDF转图片功能必需）：**

**用途说明**：
- pdf2image库依赖Poppler工具将PDF页面转换为图片
- 仅在使用`convert_to_images`函数或`--convert`命令行选项时需要
- 仅提取PDF内嵌图片（extract_images）不需要安装Poppler

**Windows安装：**
1. 访问 [Poppler for Windows](http://blog.alivate.com.au/poppler-windows/) 下载最新版本
2. 解压到任意目录，例如 `C:\poppler`
3. 将解压后的 `bin` 目录添加到系统环境变量 PATH 中
4. 重启命令行窗口

**Linux (Ubuntu/Debian)安装：**
```bash
sudo apt-get install poppler-utils
```

**macOS安装：**
```bash
brew install poppler
```

**验证安装：**
```bash
pdfinfo -v
```

**测试兼容说明**：
- 对于未安装Poppler的环境，使用条件跳过相关测试
- 单元测试使用mock技术模拟Poppler依赖，确保测试覆盖率
