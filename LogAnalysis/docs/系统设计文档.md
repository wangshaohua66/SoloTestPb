# 日志聚合分析平台 - 系统设计文档

## 一、系统概述

### 1.1 项目背景

日志聚合分析平台是面向运维人员的日志管理工具，用于收集、解析、聚合多源日志数据，支持日志检索、统计分析、异常告警，帮助快速定位系统问题。

### 1.2 系统目标

- 支持多种日志来源（文件、标准输出、网络端口、API）
- 自动识别和解析常见日志格式
- 提供灵活的日志检索和过滤功能
- 多维度日志聚合和统计分析
- 实时异常检测和告警通知
- 报表导出功能

### 1.3 技术栈

| 层级 | 技术选型 | 版本 |
|------|----------|------|
| 后端语言 | Python | 3.13 |
| Web框架 | Flask | 3.0.3 |
| ORM | Flask-SQLAlchemy | 3.1.1 |
| 定时任务 | APScheduler | 3.10.4 |
| 数据库 | SQLite | - |
| 前端框架 | Vue | 3.x |
| 构建工具 | Vite | - |
| UI组件库 | Element Plus | - |
| 图表库 | ECharts | - |

## 四、核心模块设计

### 4.1 日志收集模块 (LogCollector)

#### 功能说明

支持从多种来源收集日志：
- **文件收集**: 实时监听日志文件，收集新增日志
- **网络收集**: 通过TCP/UDP端口接收日志
- **API收集**: 通过HTTP API接收日志

#### 关键设计

- 多线程并行收集，互不干扰
- 支持动态启停收集器
- 文件收集使用尾追踪(tail)机制

### 4.2 日志解析模块 (LogParser)

#### 功能说明

自动解析日志内容，提取关键字段：
- 时间戳
- 日志级别
- 模块名称
- 消息内容
- 其他自定义字段

#### 内置解析格式

| 格式名称 | 正则表达式 | 适用场景 |
|----------|------------|----------|
| nginx_access | Nginx访问日志格式 | Web服务器日志 |
| python_default | Python logging格式 | Python应用 |
| java_logback | Java Logback格式 | Java应用 |
| syslog_rfc3164 | Syslog RFC3164 | 系统日志 |
| json | JSON格式 | 结构化日志 |

### 4.3 日志聚合模块 (LogAggregator)

#### 功能说明

提供多维度的日志聚合统计：
- 按级别聚合
- 按服务聚合
- 按模块聚合
- 按时间窗口聚合
- 错误率计算
- 趋势分析

### 4.4 告警引擎 (AlertEngine)

#### 功能说明

实时检测异常日志，触发告警：

#### 支持的条件类型

| 类型 | 说明 | 配置示例 |
|------|------|----------|
| keyword | 关键词匹配 | `{"keywords": ["error", "exception"], "threshold": 5}` |
| level_threshold | 级别阈值 | `{"level": "ERROR", "threshold": 10}` |
| error_rate | 错误率 | `{"threshold": 5.0}` |
| custom_query | 自定义查询 | `{"query": "...", "threshold": 1}` |

### 4.5 报表生成模块 (ReportGenerator)

#### 功能说明

生成各类日志分析报表：

#### 报表类型

| 类型 | 说明 | 包含内容 |
|------|------|----------|
| summary | 汇总报表 | 总览统计、级别分布、服务分布 |
| detailed | 详细报表 | 汇总 + 详细日志列表 |
| daily | 日报 | 当日统计数据 |
| weekly | 周报 | 一周统计数据 |

#### 导出格式

- JSON格式
- 纯文本格式

## 八、扩展能力

### 8.1 日志来源扩展

可通过实现新的收集器类扩展支持更多来源：
- Docker容器日志
- Kubernetes日志
- 云平台日志（AWS CloudWatch、阿里云SLS）

### 8.2 解析规则扩展

支持用户自定义正则表达式解析规则，使用命名捕获组提取字段。

### 8.3 告警通道扩展

当前告警仅记录到数据库，可扩展支持：
- 邮件通知
- 企业微信/钉钉机器人
- 短信通知
- Webhook回调
