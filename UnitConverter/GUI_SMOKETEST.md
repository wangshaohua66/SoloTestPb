## 构建和运行命令

### 构建

```bash
# macOS
mvn clean package -Pmacos

# Windows
mvn clean package -Pwindows

# Linux
mvn clean package -Plinux
```

### 运行

```bash
# macOS
./run.sh

# Windows
run.bat

# Linux
./run_linux.sh

# 或直接使用包含 JavaFX 的 Java
"/Library/Internet Plug-Ins/JavaAppletPlugin.plugin/Contents/Home/bin/java" -jar target/UnitConverter-1.0.0.jar
```

---

## 已知限制

1. **JavaFX 依赖**: 运行时需要 JDK 8 包含 JavaFX（如 Oracle JDK 8、ZuluFX 8）
2. **Amazon Corretto 8**: 无头版不包含 JavaFX，需要使用系统 Java 插件或安装完整 JDK
