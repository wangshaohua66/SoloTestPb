## 1. 系统启动

### 1.1 环境要求

- **Python**: 3.13 或更高版本
- **Node.js**: 16.x 或更高版本
- **操作系统**: macOS / Linux / Windows

### 1.2 启动步骤

#### 步骤1：启动后端服务

```bash
# 进入后端目录
cd ArtifactRestore/backend

# 创建并激活虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 启动服务
python run.py
```

启动成功后会显示：
```
============================================================
       文物修复记录系统 - 后端服务
============================================================
服务地址: http://127.0.0.1:5002
============================================================
 * Running on http://0.0.0.0:5002
```

#### 步骤2：启动前端服务

```bash
# 进入前端目录（新开一个终端）
cd ArtifactRestore/frontend

# 安装依赖
npm install

# 启动开发服务
npm run dev
```

启动成功后会显示：
```
  VITE v5.0.8  ready in 300 ms

  ➜  Local:   http://localhost:8002/
  ➜  Network: http://192.168.x.x:8002/
```

#### 步骤3：访问系统

打开浏览器，访问：http://127.0.0.1:8002

## 3. 文物档案管理

点击左侧菜单的「文物档案」进入文物档案管理页面。

### 3.1 搜索功能

页面顶部提供搜索栏：
- **关键词搜索** - 输入文物名称、年代或类别进行搜索
- **搜索按钮** - 执行搜索
- **重置按钮** - 清空搜索条件，显示全部文物

### 3.2 文物列表

列表显示以下信息：
- **ID** - 系统自动生成的唯一标识
- **文物名称** - 文物的名称
- **年代** - 文物所属年代
- **类别** - 文物类别（如：青铜器、书画等）
- **材质** - 文物材质
- **尺寸** - 文物尺寸
- **创建时间** - 记录创建时间
- **操作** - 详情/编辑/删除

### 3.3 操作说明

#### 新建文物

1. 点击「新建文物」按钮
2. 在弹出的表单中填写以下信息：
   - **文物名称**（必填）- 文物的正式名称（1-100字符）
   - **年代** - 如：唐代、宋代、明代等
   - **类别** - 如：青铜器、陶瓷、书画、玉石等
   - **尺寸** - 如：高30cm，宽15cm
   - **材质** - 如：青铜、陶瓷、丝绸、木质等
   - **保存状态** - 详细描述文物当前的保存状况
   - **病害描述** - 描述文物存在的病害问题
3. 点击「确定」保存

#### 编辑文物

1. 点击文物列表中的「编辑」按钮
2. 在弹出的表单中修改需要更新的信息
3. 点击「确定」保存修改

#### 删除文物

1. 点击文物列表中的「删除」按钮
2. 在确认对话框中点击「确定」
3. 文物及其所有关联数据（计划、记录、影像、材料）将被删除

#### 查看详情

1. 点击文物列表中的「详情」按钮
2. 进入文物详情页面（详见第4章）

### 3.4 分页功能

列表底部提供分页控制：
- **每页条数** - 可选 10/20/50 条
- **翻页** - 上一页、下一页、跳转到指定页

## 4. 文物详情管理

进入文物详情页后，可以看到五个标签页，分别管理不同类型的数据。

> **性能优化**：详情页采用Tab懒加载机制，只在用户首次切换到某Tab时才请求数据，已加载的数据会缓存避免重复请求。

### 4.1 基本信息

显示文物的详细信息，可点击「编辑」按钮进行修改。

显示内容：
- 文物名称
- 年代
- 类别
- 尺寸
- 材质
- 保存状态
- 病害描述
- 创建时间

### 4.2 修复计划

管理该文物的修复计划。

#### 添加修复计划

1. 点击「添加计划」按钮
2. 填写以下信息：
   - **修复目标**（必填）- 本次修复要达成的目标（2-500字符）
   - **修复方法**（必填）- 采用的修复技术和方法（2-500字符）
   - **使用材料** - 计划使用的主要材料
   - **预计工期**（必填）- 预计完成时间（如：15天、3个月）
3. 点击「保存」

#### 编辑/删除计划

- 点击「编辑」按钮修改计划
- 点击「删除」按钮删除计划（需确认）

### 4.3 过程记录

按时间顺序记录修复过程。

#### 添加过程记录

1. 点击「添加记录」按钮
2. 填写以下信息：
   - **记录时间**（必填）- 选择修复操作的时间
   - **操作步骤**（必填）- 详细的操作描述（2-1000字符）
   - **使用材料** - 本次操作使用的材料
   - **工具设备** - 使用的工具和设备
   - **遇到问题** - 修复过程中遇到的问题及处理方法
3. 点击「保存」

**建议**：每次完成一项修复操作后及时记录，保持记录的完整性和连续性。

### 4.4 影像管理

按阶段管理修复影像资料，分为三个阶段：
- **修复前** - 修复开始前的照片
- **修复中** - 修复过程中的照片
- **修复后** - 修复完成后的照片

#### 添加影像

1. 点击「添加影像」按钮
2. 填写以下信息：
   - **阶段** - 选择修复前/修复中/修复后
   - **描述** - 影像内容的详细描述
   - **上传文件**（可选）- 选择图片文件上传（支持 jpg/png/gif）
3. 点击「保存」

**说明**：即使不上传文件，也可以创建影像记录（仅记录描述）。

#### 图片预览

- 点击任意图片可放大查看
- 支持幻灯片播放模式
- 图片加载失败时有容错处理

### 4.5 材料管理

记录修复过程中使用的材料。

#### 添加材料记录

1. 点击「添加材料」按钮
2. 填写以下信息：
   - **材料名称**（必填）- 如：环氧树脂、丙酮、修复泥等（1-100字符）
   - **材料来源** - 购买渠道或生产厂家
   - **用量**（必填）- 使用数量（如：50ml、100g）
   - **备注** - 其他需要说明的信息
3. 点击「保存」

   - 卡片式网格布局
   - 显示阶段标签（黄色=修复前、蓝色=修复中、绿色=修复后）

   - 点击卡片放大查看图片
   - 支持幻灯片播放
   - 支持切换到其他图片

4. **操作功能**
   - **上传影像** - 快速上传新影像，支持文件上传
   - **编辑** - 修改影像描述和阶段
   - **删除** - 删除影像记录
   - 点击文物名称跳转详情页

### 5.4 材料管理页

**访问路径**：左侧菜单 → 材料管理

此页面汇总显示所有材料使用记录，包含统计信息。

#### 功能特性

1. **统计信息**
   - 材料记录总数
   - 材料种类数（去重）
   - 关联文物数

2. **搜索筛选**
   - 按材料名称搜索

3. **列表展示**
   - 材料名称（彩色标签区分）
   - 关联文物（可点击跳转）
   - 来源、用量、备注
   - 记录时间

4. **操作功能**
   - **新增材料** - 快速添加材料记录
   - **编辑** - 修改材料信息
   - **删除** - 删除材料记录
   - **查看文物** - 跳转到关联文物详情页

## 6. 档案导出

点击左侧菜单的「档案导出」进入导出页面。

### 6.1 页面结构

导出页面包含两个Tab：
- **批量导出** - 选择多个文物导出
- **导出历史** - 查看历史导出记录

### 6.2 批量导出

#### 可导出文物列表

页面显示系统中所有可导出的文物，支持：
- 多选框选择
- 全选/取消全选
- 按名称、年代、类别搜索

#### 导出格式

支持两种导出格式：
- **TXT格式** - 纯文本格式，适合打印和阅读
- **JSON格式** - 结构化数据，适合程序处理

#### 导出操作

1. 勾选需要导出的文物（可多选）
2. 选择导出格式（TXT/JSON）
3. 点击「批量导出」按钮
4. 浏览器会自动下载导出文件

#### 导出报告内容

导出的报告包含以下五个部分：

**【一】文物基本信息**
- 文物名称、年代、类别
- 尺寸、材质
- 保存状态、病害描述
- 建档时间

**【二】修复计划**
- 修复目标、方法
- 使用材料
- 预计工期
- 制定时间

**【三】修复过程记录**
- 按时间顺序排列
- 操作步骤、使用材料
- 工具设备、遇到问题
- 记录时间

**【四】影像资料**
- 按阶段分组（修复前/修复中/修复后）
- 影像描述、文件名称
- 记录时间

**【五】材料使用记录**
- 材料名称、来源
- 用量、备注
- 记录时间

### 6.3 导出历史

查看历史导出记录，显示：
- 导出的文物列表
- 导出数量
- 导出格式
- 导出时间

## 7. 常见问题

### Q1: 后端启动时提示模块未找到？

A: 请确保已安装所有依赖：
```bash
cd backend
pip install -r requirements.txt
```

### Q2: 前端启动时提示端口被占用？

A: 可以修改 `frontend/vite.config.js` 中的端口配置，或停止占用8002端口的程序。

### Q3: 上传图片失败？

A: 请检查：
- 图片格式是否为 jpg/png/gif
- 文件大小是否超过16MB
- 后端 `backend/app/static/images` 目录是否有写入权限

### Q4: 数据保存在哪里？

A: 所有数据保存在 SQLite 数据库文件 `backend/app.db` 中。上传的图片保存在 `backend/app/static/images/` 目录。

### Q5: 如何备份数据？

A: 直接备份以下文件/目录：
- `backend/app.db` - 数据库文件
- `backend/app/static/images/` - 上传的图片
- `backend/logs/` - 日志文件（可选）

### Q6: 独立管理页面有什么用？

A: 独立管理页面提供了全局视角：
- **修复计划列表**：查看所有文物的修复计划，而不是单个文物
- **过程记录时间线**：按时间顺序查看所有修复过程，便于了解整体修复进度
- **影像资料库**：集中管理所有图片，支持跨文物浏览
- **材料管理**：统计材料使用情况，便于耗材管理

### Q7: 批量导出时为什么要选格式？

A: 两种格式各有用途：
- **TXT**：适合打印、存档、人工阅读
- **JSON**：适合与其他系统集成、数据分析、程序处理

### Q8: 新增功能的验证？

A: 可以通过以下步骤验证新功能：
1. 创建3个不同类别的文物
2. 在各独立管理页面试试新增功能
3. 在影像库上传测试图片
4. 测试批量导出功能
5. 检查导出历史是否记录
